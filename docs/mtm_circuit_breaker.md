# MTM 서킷브레이커 — 설계·백테스트 (2026-07-06)

> 배경: 과열 사전필터는 데이터 기각(docs/box_model_review_202607.md).
> 그리드의 실질 꼬리 리스크는 "지속 드리프트 → 하락매수 인벤토리 누적 → MTM 손실".
> 이를 사후에 자동 차단하는 규칙을 103개월 walk-forward로 검증.

## 규칙 (확정)

- 가상 그리드 미실현 손실(MTM)이 **투입자본의 2%** 를 넘으면 → **신규 매수 정지 권고**
- 보유분 익절 매도는 계속 (인벤토리 자연 해소)
- MTM이 **1%(θ×0.5)** 이내로 회복되면 매수 재개 (히스테리시스)
- `config.MTM_CIRCUIT_THRESHOLD=0.02`, `MTM_CIRCUIT_RESUME=0.5`

## 백테스트 (reports/mtm_circuit_backtest.py — 103개월, 1σ 박스, 0.2%/0.4%, 실측보정 1.6)

| θ | 월평균 순익 | 최악월 | 최악 드로다운 | 월거래량 |
|---|---|---|---|---|
| 0.5% | −3.4만 | −46.9만 | −61.0만 | 0.77억 |
| 1% | −4.7만 | −73.5만 | −86.6만 | 0.94억 |
| **2% (채택)** | **−5.5만** | **−101.5만** | **−116.3만** | **1.15억** |
| 3% | −5.4만 | −118.7만 | −135.8만 | 1.27억 |
| 5% | −4.6만 | −144.4만 | −167.3만 | 1.44억 |
| 없음(현행) | −4.9만 | −222.3만 | −279.3만 | 1.52억 |

- **평균 손익은 θ에 둔감(월 ±2만, 노이즈) — 꼬리 위험만 극적으로 감소**: "보험료 ≈ 0인 꼬리 보험".
- θ=2% 채택 근거: 최악월·드로다운 절반 이하, 거래량 −24%(리워드 티어 영향 제한),
  성공월(횡보) 발동률 68%로 과도하지 않음. θ=0.5%는 발동 86%로 사실상 상시 정지 → 기각.
- 절대 수준(음수)은 시뮬 보수성(월 고정 박스+MTM 전액 인식) 탓 — θ 간 상대 비교 목적으로만 해석.
  실전(월중 리셋 운영)의 pnl율은 +0.088%.

## 6월 실패월 재현 검증

사용자 실설정(1σ 90.889~105.23M, 0.2%/0.3%)으로 6월 일봉 재현:
- **6/3 발동**(월초 급락 108→95M에 즉시 반응) — 미발동 시 가상 MTM 최저 **−6.26%**
- 6/24~30 추가 하락(94.5→89.2M) 구간의 인벤토리 누적을 차단했을 것.
