# BTC 그리드 운영 3모드 — 개념 정의

> 빗썸 BTC/KRW 레이어드 그리드의 운영 모드를 3가지로 정의한다.
> 박스권(1σ/2σ) 예측과 매수/매도 간격 추정은 로컬 앱(`api_server.py` + `utils/interval_optimizer.py`)이
> 1분봉 시뮬레이션으로 모드별로 산출한다.
> 정밀 간격 수치는 거래내역 확보 후 캘리브레이션으로 확정한다(아래 "확정 대기" 참조).

## 공통 전제

- **박스권**: 월간 σ 추정 → 1σ 박스 `[l1, u1]`, 2σ 박스 `[l2, u2]` (비대칭 σ 반영).
- **수수료**: 빗썸 편도 0.04%(왕복 0.08%). 매도 간격이 이보다 좁으면 그리드 자체 손실.
- **리워드**: 전월 거래량으로 당월 요율 결정(티어 0.003%~0.020%), 월 상한 300만원.
- **거래량 목표 파라미터**: 멤버십/리워드 티어 달성용 목표 월거래량(예: 10억, 100억).

각 모드는 "거래량(=리워드)"과 "매매 스프레드 수익"의 **가중치**가 다르다.

---

## 1. 일반모드 — 수익 극대화

- **목적**: 박스권(특히 1σ) 내 진동에서 **매매수익 + 리워드 합산이 최대**가 되도록 간격 설정.
- **거래량 목표와 무관** — 목표 거래량을 좇지 않고 왕복 순익을 우선한다.
- **간격**: 매도 간격을 넓혀(왕복당 스프레드 ≫ 수수료) 왕복 순익 극대화. 탐색 공간 = 넓은 간격.
- **최적화 목적함수**: `objective = "net"` (월 순익 = 그리드수익 − 수수료 + 리워드 + MTM 최대).
- **운영 시점**: 상시(거래량 목표 미설정 시 기본), 또는 부스트로 목표 달성 후 잔여 기간.
- **USDT 비유**: 1원 매수 / 3원 매도를 1σ·2σ 모두 적용.

## 2. 부스트모드 — 거래량 극대화

- **목적**: 초미세 매수/매도 반복으로 **거래량을 빠르게 확보** → 다음달 리워드 멤버십 등급 달성.
- **목표 거래량과 연동** — 파라미터의 목표(10억/100억 등)에 도달하면 **중지**, 예수금을 일반모드로 전환 가능.
- **간격**: 매수/매도 모두 초촘촘(매도 ≈ 수수료 수준). 탐색 공간 = 좁은 간격.
- **최적화 목적함수**: `objective = "volume"` (그리드가 수수료를 까먹지 않는 `grid ≥ 0` 범위에서 거래량 최대).
- **운영 시점**: 월 초(~8일)~중기(~16일)에 목표 달성 목표. 달성 시 조기 종료.
- **USDT 비유**: 1원 매수 / 1원 매도를 1σ·2σ 모두 적용.

## 3. 듀얼모드 — 거래량·수익 동시 추구

- **목적**: 한 운영 안에서 **1σ 영역은 부스트, 2σ 영역(바깥 링)은 일반**으로 동시 운영하여
  거래량과 매매수익을 양호한 수준으로 **병행**한다. (반대 배치도 옵션으로 허용)
- **자본 배분**: 투입자본을 `dual_inner_ratio`로 1σ(부스트) / 2σ(일반) 두 그리드에 나눈다(기본 0.6 = 1σ 60%).
- **간격**:
  - 1σ 밴드 `[l1,u1]` → 부스트 간격(초촘촘, `objective="volume"`)
  - 2σ 밴드 `[l2,u2]` → 일반 간격(넓게, `objective="net"`)
- **리워드 합산 주의**: 두 그리드의 거래량을 **합산한 총거래량**에 요율을 1회 적용하고 300만원 상한을 적용
  (밴드별로 리워드를 따로 매겨 중복/이중 상한 적용하지 않는다).
- **운영 시점**: 월 하순(~24일)경 거래량 목표 달성을 노린다(부스트만큼 빠르지 않지만 수익도 챙김).
- **USDT 비유**: 1σ에 1원 매수/1원 매도(부스트), 2σ에 1원 매수/3원 매도(일반).

## 모드 비교 요약

| 항목 | 일반 | 부스트 | 듀얼 |
|---|---|---|---|
| 1차 목표 | 매매수익 | 거래량(리워드 등급) | 거래량+수익 병행 |
| 목적함수 | net 최대 | volume 최대(grid≥0) | 1σ=volume / 2σ=net |
| 매도 간격 | 넓음 | 초촘촘(≈수수료) | 1σ 촘촘 / 2σ 넓음 |
| 거래량 목표 연동 | 무관 | 강하게 연동 | 연동(완만) |
| 권장 운영 구간 | 상시 / 목표 달성 후 | 월초~중기(~16일) | 월 하순(~24일) |
| 자본 운용 | 단일 밴드 | 단일 밴드 | 1σ/2σ 분할(inner_ratio) |

## 로컬 앱 산출 구조

- `utils/interval_optimizer.optimize_intervals(...)` → `boost` / `normal` / `dual` 3개 결과 반환.
  - `boost`, `normal`: 단일 박스(권장 밴드) 격자 탐색.
  - `dual`: 1σ 밴드 부스트 + 2σ 밴드 일반을 각각 산출 후, 거래량 합산·리워드 1회 적용으로 결합.
    반환에 `inner`(1σ 부스트 leg)·`outer`(2σ 일반 leg) 상세 포함.
- `/api/intervals` 응답에 세 모드 모두 포함. `index.html` 간격 추정 패널에 3행으로 표시.
