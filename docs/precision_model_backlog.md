3. **ML 고도화 검토**
   - 피처 후보: 일봉 변동폭, 시장 거래대금, 김프, 요일
   - 예측 대상: 주간 봇 거래대금, 왕복횟수, 순익
   - 데이터 포인트가 아직 2개뿐 → 단순 회귀부터 시작하는 로드맵

4. **리워드 연동 총손익 모델**

   - 현재 USDT 박스권 σ는 프론트엔드 상수(`index.html` `USDT.sigma_pct = 2.2`)로 고정 →
     백엔드의 USDT 예측(`predict_as_of(symbol="USDT")`, `config.py`의 σ_blend = (1-w)·σ_usdt + w·σ_fx)
     결과와 연결되어 있지 않음.
   - **정정 메모**: "USDT 분봉 미수집"은 사실이 아님. USDT 분봉은 정상 수집됨
     (`utils/minute_data.py` MARKETS에 KRW-USDT 포함, 시드/증분 수집 동작).
     다만 KRW-USDT 5분봉 히스토리가 2024-06~로 BTC보다 짧아 σ 추정 시 환율 σ와 블렌딩해 보완하는 구조.
   - 할 일: BTC처럼 USDT 박스권도 백엔드 `predict_as_of` 결과(σ 포함)를 받아오도록 프론트 연결.
     `index.html`의 `updateUsdtModel`이 상수 σ 대신 백엔드 스냅을 사용하도록 변경.
