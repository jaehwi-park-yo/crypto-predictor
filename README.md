# 가상화폐 박스권 예측 & 그리드 매매 기획 시스템

빗썸 원화마켓(BTC_KRW)에서 **박스권 그리드 매매**를 위한 익월 박스권을
**통계 기반(1σ/2σ)**으로 예측하고, 그리드 봇 파라미터와 리워드 전망을
산출하는 멀티 에이전트 시스템.

## 에이전트 구조

```
        🎯 오케스트레이터 (전체 구조관리 · 운영지시 · 일정관리)
                          │
   ┌────────┬────────┬────┴───┬────────┬────────┐
   ▼        ▼        ▼        ▼        ▼        ▼
 ① 수집   ② 분석   ③ 예측   ④ 그리드  ⑤ 리워드  ⑥ 리스크
```

| 에이전트 | 파일 | 역할 |
|---|---|---|
| 🎯 오케스트레이터 | `main.py` | 파이프라인 지휘, 리포트 생성, 일정관리 |
| ① 데이터수집 | `agents/data_collector.py` | 빗썸/글로벌/매크로 수집 (오프라인 폴백) |
| ② 시장분석 | `agents/market_analyzer.py` | 지표 산출 + 시나리오 분류 |
| ③ 박스권예측 | `agents/box_predictor.py` | 1σ/2σ 통계 박스권 예측 (핵심) |
| ④ 그리드최적화 | `agents/grid_optimizer.py` | 간격·봇수·자본배분 (수수료 인지) |
| ⑤ 리워드계산 | `agents/reward_calculator.py` | 구간 판정·목표추천·페이스점검 |
| ⑥ 리스크모니터 | `agents/risk_monitor.py` | 이탈 판정 + 비대칭 대응 |

## 핵심 설계 원칙 (확정)

1. **자본 변수화** — 4천만원 기준, 재투자로 변동. 목표 리워드 구간은 자본의 함수로 자동 설정.
2. **빗썸 수수료 0.04%** — 왕복 0.08% > 리워드 0.008~0.02%. 리워드는 *수수료 환급* 성격이며 실제 수익은 그리드 스프레드. 그리드 간격은 수수료 인지 최소(≈0.24%) 제약.
3. **원화 보유 비중** — KRW 현금을 헷지/물타기 예비로 보유 (`KRW_HOLD_RATIO`, 기본 30%). USDT-KRW는 보류 모듈.
4. **비대칭 리스크** — 관망 기본 / 상방 이탈 관망 유지 / 하방 이탈 30% 부분손절 + 박스 재설정.
5. **통계 1σ/2σ** — 로그수익률 → 월간 √t 투영. 1σ=정상 운영범위(68.3%), 2σ=이탈 경보선(95.5%).

## 실행

```bash
pip install -r requirements.txt

python main.py                            # 기본 자본으로 익월 예측
python main.py --capital 60000000         # 재투자 반영 (자본 변경)
python main.py --month 2026-07            # 대상 월 지정
python main.py --aggressiveness aggressive # 공격성 다이얼 변경
```

### 공격성 다이얼 (거래량 vs 수수료 절충)

| 레벨 | 그리드 간격 | 성향 | 비고 |
|---|---|---|---|
| `conservative` | 1.0% | 수수료 절약·안정 | 봇 최소, 리워드 낮음 |
| `balanced` (기본) | 0.5% | 매매수익·리워드 균형 | **현재 채택** |
| `aggressive` | 0.3% | 거래량/리워드 극대화 | 봇·수수료·슬리피지↑ |

> 왕복 수수료 0.08%가 리워드 상한 0.02%보다 크므로, 그리드 간격은 항상
> 수수료 인지 최소(≈0.24%) 이상으로 강제됩니다.

> 네트워크가 없으면 합성 데이터로 폴백해 파이프라인이 그대로 동작합니다.
> 리포트는 `reports/{YYYY-MM}_report.txt`에 저장됩니다.

## 주의

- 거래량/리워드 추정치는 **명시적 가정 기반 휴리스틱**이며 실거래 데이터로 보정해야 합니다 (`config.py`의 `GRID_FILL_EFFICIENCY` 등).
- 본 시스템은 **기획/예측·파라미터 산출용**이며 실제 주문 실행(비공개 API) 기능은 포함하지 않습니다.
