# 그리드 매수/매도 간격 최적화 백테스트 결과

**데이터:** `data/dataset_seed.zip` 5분봉 (KRW-BTC 2017-09~, KRW-USDT 2024-06~)
**실행:** `python3 reports/grid_interval_backtest.py`

## 방법론
- 실제 5분봉 경로로 **단일 인벤토리 그리드 봇**을 시뮬레이션 (매수 라인 하락 체결 →
  +m스텝 도달 시에만 익절 매도 → 재무장). 합성 경로·효율보정 없음.
- 박스권: `monthly_labels`(as-of 예측, 미래정보 누설 없음)의 **1σ 박스**.
- 자본: 4,000만 × (1−KRW 0.30) × (BTC 60% / USDT 40%) = BTC 16.8M / USDT 11.2M.
- 리워드: 전월 거래량 티어 → **10억↑ 0.015% / 100억↑ 0.018%**, 월 300만원 캡.
- **정산 기준 3종 비교** (미청산 인벤토리 평가손익 MTM 처리 차이):
  - `실현` : MTM 무시, 완료 왕복만 집계 (앱 P&L 개념). 매도간격이 상한으로 발산 → 제약 필요.
  - `이월` : 월별 청산 없이 운용, 기간말 미청산분만 1회 정산 (버티기 전략).
  - `월MTM`: 매월 박스 재예측 시점에 미청산 인벤토리를 종가로 청산 정산 (가장 보수적).

## 결과 (월평균 순익, 전월 10억↑ 리워드 기준)

|---|---|---|---|
| 전체 2017-12~ | 실현 / 이월 / 월MTM | 0.13% / 2.50% | +29.0 / +28.7 / **−0.5만** |
| 최근 2023-01~ | 실현 / 이월 / 월MTM | 0.13% / 2.50% | +27.7 / +26.8 / **+10.1만** |
| 최근 2024-06~ | 실현 / 이월 / 월MTM | 0.13~0.30% / 2.5% | +28.0 / +26.5 / **+3.9만** |

|---|---|---|---|

## 핵심 결론
1. **최적 간격은 정산기준·기간에 거의 무관하게 일정.** BTC ≈ **매수 0.13%(촘촘) / 매도 2.5%**,
   USDT ≈ **매수 1~3원 / 매도 3원**. 즉 "촘촘한 매수 + 넓은 매도(저점매집·길게익절)"가 일관된 방향.
   정산 방식은 *간격 선택*이 아니라 *절대 수익 수준*만 바꾼다.
2. **전월 거래량 티어(10억↑/100억↑)는 사실상 무관.** 실측 거래량(0.2~0.8억/월)이 리워드 캡
   (300만원=약 200억/월)에 한참 못 미쳐 리워드 기여 0.3~1.4만/월. 두 케이스 최적 간격 동일.
3. **수익은 정산·국면에 크게 좌우.** 실현 기준 BTC +29만/월이지만, 매월 청산(월MTM) 기준이면
   전체기간 본전(2018·2022 약세장 캐리손실 −29만이 그리드익 30만을 상쇄). 실제값은
   `이월`과 `월MTM` 사이 — 약세장 물량을 얼마나 버티느냐에 달림.
4. ⚠️ **앱의 교차-카운트 P&L은 `실현`보다도 과대(월 300만+).** 모든 라인통과를 왕복으로 세고
   미청산 손실을 무시하기 때문. 실측 단일인벤토리 기준 현실적 그리드 순익은 월 수만~수십만원대.
